# Splash Lines

Every time Slack starts, BetterSlack's loading screen shows a line under its mark, picked at random from a list -- the way Minecraft greets you with a yellow sentence on its title screen.

- **It ships with a hundred lines** about the office's running jokes: releases on a Friday, the cache that was always the cache, payments in Canadian dollars, AB tests in their eleventh phase, and everything waiting for JL's sign-off.
- **The list is yours.** Open the plugin's settings: the lines are in a text box, and **Expand** opens it full size. One line per entry; blank lines and lines starting with `#` are skipped, so the list can be kept in sections. **Restore the original** puts the shipped list back.
- **Another one, now:** the command palette has *Another splash line*, which shows one in a toast.

It is switched on for everybody the first time BetterSlack starts with it. Switch it off and it stays off.

What it does not do: it does not hold Slack up so you can finish reading. The screen lifts when the mods are in, as it always has.
